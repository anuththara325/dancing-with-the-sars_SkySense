DANCING WITH THE SARs  -  Team SkySense
NASA Space Apps Challenge, Colombo 2026
Challenge: Dancing with the SARs

An interactive web app of seven NASA-ISRO NISAR L-band radar stories
(Thailand, India, Nepal and Sri Lanka, June to November 2026), with a
Rain test at three places in Sri Lanka and a plain-words guide to radar.

Team: Anuththara Divyanjalie, Muditha Kumara, Mayumi Maleesha


HOW TO OPEN THE APP
-------------------

Option 1: open the live link (nothing to download)

    https://anuththara325.github.io/dancing-with-the-sars_SkySense/

Option 2: download and open the files

    1. Download the zip file "dancing with sars team sky sense.zip".
    2. Extract (unzip) it to any folder.
    3. Open the file "index.html" in a web browser (Chrome, Edge,
       Firefox or Safari).

Keep all the extracted files and folders together (index.html, app.js,
style.css, the img and media folders). The app needs them next to
index.html.


WHAT IS INSIDE
--------------

    index.html          the page
    app.js, style.css   the app code and styles
    data*.js            the numbers and text behind each story
    img/                the radar, optical and chart images
    media/              the looping video on the home page
    README.md           technical notes (data, methods, limits)
    LICENSE             MIT licence for our code


WHERE TO START
--------------

    Home page           pick one of the seven stories
    New to radar?       a plain-words guide (top menu)
    Polarizations       what HH and HV show, plus vegetation density
    Rain test           does the radar colour follow real rain?

All results are described as "consistent with", not proof. Every story
lists its limits. Data are provisional NISAR products where marked.
